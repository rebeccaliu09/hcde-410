# A1 — Working with Open Data

**Author:** Rebecca Liu
**Dataset:** Burke-Gilman Trail counter north of NE 70th St
**Data retrieved:** 2026-10-13
**Period analyzed:** 2019

**Source:** https://data.seattle.gov/Transportation/Burke-Gilman-Trail-north-of-NE-70th-St-Bicycle-and/2z5v-ecg8

## Questions I asked
- When is the trail busiest and quietest?
- Do cyclists and pedestrians use the trail at different times?
- Do weekday and weekend patterns suggest commuting?
- Does travel direction change between morning and evening?

## How to re-run
Open `A1.ipynb` in Jupyter Notebook with Python 3 and run all cells from top to bottom.

Required packages: `requests`, `pandas`, and `matplotlib`.
Internet access is needed to retrieve data from Seattle's API.
