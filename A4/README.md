# HCDE 410 Final Project: What F1 Lets Us Hear

An exploratory data study of the Formula 1 team radio messages that F1 chose to make public in the 2023–2024 seasons: 
which drivers, which moments of a race, and what kinds of messages get released. Data comes from the public [OpenF1 API](https://openf1.org).

See `proposal.ipynb` for the preliminary proposal.
